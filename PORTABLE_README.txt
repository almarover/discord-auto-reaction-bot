Discord Auto Reaction Bot 便携版
================================

启动方式
--------
双击“Discord Auto Reaction Bot.exe”。

首次使用
--------
1. 在主页填写自己的 Discord Bot Token 并保存。
2. 启动 Bot，等待服务器列表同步。
3. 在“公共”和“配置”页面设置服务器、目标用户和 Reaction。

重要说明
--------
- 首次收到本程序时不包含 Token、用户 ID、服务器配置或日志。
- 请勿把已经填写 Token 的程序文件夹直接发送给其他人。
- 配置完成后，程序会在本文件夹生成 .env 和若干 JSON 配置文件。
- 移动程序时应移动整个文件夹，不能只移动最外层 EXE。
- Windows 可能提示未知发布者，这是因为本程序没有购买代码签名证书。

停止与退出
----------
可在主页停止 Bot；选择“退出管理器”会结束管理界面。
